\# 🚗 LetDriver Game (Unity)



This project is a \*\*Unity-based driving simulation game\*\* designed to help players learn \*\*real traffic rules and safe driving habits\*\* through interactive gameplay.



Players select a car, drive through roads with traffic signs, follow traffic laws, and complete missions. Violations reduce lives, while successful driving leads to winning the game.



---



\## 🎯 Game Objectives



\- Teach players real-world traffic rules

\- Improve safe driving awareness

\- Practice reacting to traffic signs and zones

\- Learn through missions, penalties, and rewards



---



\## 🎮 Game Features



\- 🚘 Car selection system (menu scene)

\- 🛣️ Realistic car movement with speed control

\- 🚦 Traffic signs \& traffic rule detection

\- ❤️ Life system (3 lives)

\- 💥 Crash detection (instant game over)

\- 🏁 Win / Lose conditions

\- 📊 Speed UI \& life UI

\- 🎵 Menu background music \& game background music

\- 🔊 Engine sound, crash sound, and UI sound effects

\- 📷 Smooth camera follow system



---



\## ⌨️ Controls



| Key | Action |

|---|---|

| \*\*W\*\* | Accelerate |

| \*\*S\*\* | Brake / Reverse |

| \*\*A\*\* | Turn Left |

| \*\*D\*\* | Turn Right |



---



\## 🗺️ Game Flow



\### 1️⃣ Car Scene (Menu Scene)

\- Player selects a car

\- Car rotates visually

\- Menu background music plays

\- Click \*\*Start\*\* to begin the game



\### 2️⃣ Game Scene

\- Selected car spawns at the spawn point

\- Player drives and follows traffic rules

\- Speed and lives are displayed on UI

\- Violations reduce lives

\- Crash or 0 lives → Game Over

\- Reach the goal zone → Win
